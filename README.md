## 🌟 Project Description

A **real-time hostel student fee management system** built using **Google Sheets as a live database**, designed for **colleges and hostels** to manage, update, and analyze student fee data **without traditional servers or databases**.

> 🧠 Whatever changes you make in the Admin Panel are **instantly reflected** in  
> Google Sheets → Dashboard → Analytics (live).

---

## ✨ Key Features

### 🧑‍💻 Admin Panel
- Add / Edit / Delete students
- Year-wise auto routing (1st / 2nd / 3rd)
- Auto balance calculation
- Live Google Sheets update
- No duplicate rows (Roll No locked)

### 📊 Dashboard & Analytics
- Total Students
- Paid vs Pending analysis
- Year-wise & branch-wise distribution
- Interactive charts
- Student detail modal

### 🔄 Real-Time Sync
- Google Sheets = **Single Source of Truth**
- No manual refresh
- No stale UI
- No local-only updates
